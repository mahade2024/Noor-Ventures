# Noor Ventures

Noor Ventures is a cross-platform mobile application built with Flutter (Dart), developed and managed using Android Studio, focusing on structured user workflows and clean, modular state management.

## Key Features
* **Cross-Platform Mobile UI:** Built using Flutter widgets for responsive mobile execution.
* **Modular Code Structure:** Clean separation of presentation layers from core business logic.
* **Efficient State Management:** Designed for smooth mobile interactions and reliable data handling.

## Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **IDE:** Android Studio / VS Code
